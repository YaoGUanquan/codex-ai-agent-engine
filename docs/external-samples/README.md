# external-samples 登记说明

本目录是本仓库 claim checker 与 integrity 审计使用的样本语料，按登记方式保留。

## 用途

- 为 `docs/ae/integrity/work-docs-sample-claims.md` 与 `docs/ae/integrity/work-docs-expanded-claims.md` 中的声明核查提供证据样本。
- 样本覆盖 `ae/prds`、`ae/plans`、`ae/gates` 与冒烟报告等真实 AE 产物形态。

## 来源

- 从 work 参照项目拷贝（拷贝时源项目未修改）；详见各 integrity 文档中的来源说明。

## 保留条件

- 在 `docs/ae/integrity/` 的声明仍以 `docs/external-samples/...` 路径引用这些文件期间：不移动、不改写、不归档本目录内容。
- 若未来 integrity 声明全部退役或改写为不再引用本目录，可整体归档到 `docs/99-archive/YYYY-MM/external-samples/` 并同步更新引用。

## 维护

- 新增样本时在本 README 补充一行来源说明，并保证对应 integrity 声明引用真实路径。
