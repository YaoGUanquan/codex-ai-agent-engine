# Runtime-neutral Motion Guidance Adaptation

## Stable Decision

External animation skill repositories are research inputs, not dependency or runtime authority. When a target project already chooses JavaScript motion, AE frontend review may require transform/opacity preference, coordinated state or timeline transitions, lifecycle cleanup, debounced layout refresh, reduced-motion handling, and lowest-supported-device verification.

Do not infer that GSAP is required, copy framework snippets, or claim browser/performance improvement without a real target route and browser evidence. Design direction and runtime choice remain target-project decisions.
